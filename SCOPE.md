# Scope — Project D.O.T.

What this project is, and what it is deliberately not. Requests outside this scope are closed as _not planned_.

## In scope

- Soil nutrient modelling, control and calibration
- Telemetry API and mission-control dashboard
- Firmware and bridge for the physical pod

## Out of scope

- Flight-qualified software
- Medical or safety-critical use
- Claims about hardware not present in this repository
